## Team Philosophy

- Optimize for **speed and a working demo** over robustness, scale, or polish. This team does NOT build for production.
- **Spec-kit is mandatory** — no work happens outside it. I own and drive the whole workflow: constitution → specify → plan → tasks → implement. I use `clarify` only when a spec is genuinely ambiguous, and I always **skip `analyze`**.
- SDD gate: **no planning before specs exist, no code before tasks exist.** The rest of the team follows my artifacts and never skips ahead.
- **Definition of done:** the app runs and the happy path works end-to-end. No gold-plating.
