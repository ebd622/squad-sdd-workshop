# Squad Decisions

## Active Decisions

- **2026-08-23 — Team mission:** Ship proof-of-concept apps fast. Not building for production — prioritize speed and a working demo over robustness, scale, or polish.
- **2026-08-23 — Spec Kit is mandatory:** No work happens outside it. Sloth (spec-kit expert) owns and drives the full workflow: constitution → specify → plan → tasks → implement. `clarify` runs only when a spec is genuinely ambiguous; `analyze` is always skipped.

- **2026-08-23 — Definition of done:** The app runs and the happy path works end-to-end. No gold-plating.
- **2026-08-23 — Testing policy:** Mouth (tester) runs only a quick happy-path smoke test — no edge cases, no coverage chasing — then moves to the next build.
